# Portfolio images

Esta pasta guarda a seleccao fotografica do portfolio da Bronze Art.

Organizacao recomendada:

- `home/` - imagens mais fortes para a primeira impressao do website.
- `casamentos/` - fotografia de casamento, com especial atencao a gesto, liturgia, familia e territorio.
- `sacramentos/` - baptismos, primeira comunhao, crisma e outros sacramentos catolicos.
- `familias-fatima/` - familias, infancia, geracoes e relacao com Fatima.
- `retrato-classico/` - retrato individual, familiar ou editorial com linguagem classica.
- `albuns-detalhes/` - albuns, impressao, detalhes fisicos, convites, texturas e objectos.
- `sobre-diogo/` - imagens do fotografo, bastidores discretos e presenca no trabalho.
- `historias-completas/` - seleccoes para galerias narrativas ou casos editoriais.

Notas de exportacao:

- JPG em sRGB.
- Lado maior entre 2500 e 3500 px.
- Sem watermark.
- Nomes simples, em minusculas, sem espacos.
- Usar hifenes: `casamento-fatima-igreja-01.jpg`.

A seleccao deve ser curta e exigente. Esta pasta nao deve funcionar como arquivo de tudo o que foi fotografado, mas como material para construir uma presenca publica coerente.
